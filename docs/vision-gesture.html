1. 흐름

vision — 손이 어디 있나
JPEG 디코딩→좌우 반전→MediaPipe Hands→손 하나 고르기
▼ 손 점 21개 [x, y, z] (손이 없으면 hand: null)
gesture — 무슨 손 모양이고 무엇을 할까
떨림 보정→손 모양 판별→4프레임 확인→기능으로 바꾸기
▼ draw · erase · hover · up · clear · next_color
web 그림판

프레임은 한 장씩 차례로 지나간다. vision은 gesture가 답해야 다음 프레임을 받고, gesture는 web 응답을 기다리지 않는다.

mp.solutions.hands.Hands(
    static_image_mode=False,   # 앞 프레임 손을 이어서 추적
    max_num_hands=1,
    model_complexity=0,        # lite
    min_detection_confidence=0.5,
    min_tracking_confidence=0.5,
)

3. 손 모양 판단 (gesture)

① 떨림 보정 — One Euro 필터

검지 끝 위치를 이전 위치와 섞는다. 손이 느리면 이전 위치를 많이 섞어 떨림을 없애고, 빠르면 적게 섞어 늦지 않게 한다.

a = _smoothing(min_cutoff + beta * speed, dt)       # 빠를수록 a가 커짐
pos = (a * x + (1 - a) * px, a * y + (1 - a) * py)

② 손가락 펴짐 — 비율과 기준선 두 개

r = 손목→손가락끝 거리 / 손목→가운데마디 거리   # 펴지면 1보다 큼

펴져 있었으면: r >= 0.95 일 때 계속 펴짐
접혀 있었으면: r >  1.1  일 때 펴짐
  • 비율이라서 손이 카메라에 가깝든 멀든 같은 기준을 쓴다.
  • 0.95~1.1 사이면 직전 상태를 유지해 펴짐·접힘이 깜빡이지 않는다.
  • 핀치(엄지 끝–검지 끝 거리 ÷ 손바닥 길이)도 0.3 / 0.45 두 기준을 쓴다.
  • 손이 화면 테두리에 걸리면 판별하지 않고 직전 동작을 이어 간다.

③ 4프레임 확인 + 선 앞부분 채우기

새 손 모양이 4프레임(약 0.27초) 연속 보여야 바꾼다. 한 프레임짜리 오인식이 걸러진다. 기다리는 동안의 위치는 모아 두었다가, 확정되면 먼저 그려서 선 앞부분이 잘리지 않게 한다.

프레임보인 모양확정 동작web에 가는 명령
10two_fingers (1)index_updraw(p10)
11two_fingers (2)index_updraw(p11)
12two_fingers (3)index_updraw(p12)
13two_fingers (4)two_fingersup → erase(p10, p11, p12) → erase(p13)

④ 실수 막기

  • 손을 잠깐 놓침: 3프레임까지는 기다리고, 그 뒤에 펜을 든다.
  • 전체 지우기: 주먹을 처음 보인 때부터 2초 유지해야 실행된다.
  • 한 번만 실행: 펜 들기·전체 지우기·다음 색은 손 모양이 바뀐 순간 한 번만 보낸다.
