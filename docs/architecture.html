  • 인증되면 nginx가 X-Session-Id를 붙여 stream에 넘긴다.
  • stream은 이 헤더만 믿는다.
  • 443과 http://localhost(80)에 같은 라우팅이 걸린다.
  • 설정 파일: services/security/nginx/snippets/routes.conf

페어링 순서

  1. PC가 http://localhost/를 연다 → 그림판 페이지.
  2. 페이지가 POST /api/session → sid · 1회용 token(60초).
  3. 페이지가 QR(https://<PC IP>/m/?token=…)을 띄우고 /ws/board를 연다.
  4. 휴대폰이 QR 스캔 → security가 토큰을 sid 쿠키로 바꾼다.
  5. 휴대폰이 /ws/stream 연결 → ⑧ connected → PC가 QR을 닫는다.
  6. 프레임 흐름: ①→③→④→⑤→⑥→⑦→②

처리 규칙

  • 최신 프레임만: ack 뒤에 다음 프레임, 처리 중에 온 건 버린다.
  • 타임아웃 200ms: ④⑤⑥ 중 하나라도 넘기면 그 프레임은 버린다.
  • 버린 이유: ack의 reason으로 확인 (예: vision_timeout, vision_502).
  • 손이 없을 때: vision hand: null → gesture up.
  • 좌표: 0~1 정규화, 좌우 반전은 vision에서만, 캔버스 변환은 브라우저에서.
  • 지연: PC 화면에 Date.now() - ts 표시 (서버 처리 → 화면 도착).

실행 환경

  • 열린 포트: 443(휴대폰), 80(PC localhost). 8000~8004는 127.0.0.1에만.
  • 네트워크: 휴대폰과 PC는 같은 Wi-Fi.
  • 방화벽: Windows에서 443 인바운드 허용 (처음 한 번).
  • PC IP: .env의 SECURITY_CERT_HOST. 비면 QR이 localhost라 휴대폰이 못 들어온다.
  • 한 번에 실행: services/security/start-windows.bat (IP 설정 + 전체 실행).
  • 인증서: 없으면 security가 자체 서명으로 만든다. 커밋하지 않는다.
  • 인증서 경고: 휴대폰은 처음 한 번 "계속", PC는 http://localhost라 경고 없음.
